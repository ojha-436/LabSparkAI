# LabSpark AI — Android (Flutter)

Native Android build of LabSpark AI. Shares Firebase (Auth + Firestore) and
the existing Cloud Run backend with the web app; only the frontend shell is
rewritten in Flutter.

- [x] Project structure, theme, routing, tokens ported from web
- [x] Firebase config wired for project `gen-lang-client-0686614374`
- [x] Onboarding carousel (3 slides)
- [x] Login / Sign-up with email + Google
- [x] Role selection (student / teacher / parent)
- [x] Bottom-nav shell with 5 tabs
- [x] Home screen with XP card, streak, quick actions

## Phase 2 (shipped)

## Before you can `flutter run`

### 1. Install Flutter SDK

```bash
brew install --cask flutter
flutter doctor      # follow any prompts (Android Studio, licenses, etc.)
```

### 2. Register an Android app in the Firebase console

1. Open <https://console.firebase.google.com/project/gen-lang-client-0686614374/settings/general/>.
2. Under **Your apps** → **Add app** → Android.
   - Package name: `com.labspark.ai`
   - App nickname: `LabSpark AI (Android)`
   - Debug SHA-1: run
     ```bash
     cd android && ./gradlew signingReport
     ```
     Copy the `SHA1` under `Variant: debug`.
3. Download the generated **`google-services.json`** and drop it into
   `android/app/google-services.json`.
4. Copy the shown **App ID** (looks like `1:686718900098:android:xxxxxxxx`)
   and paste it into `lib/firebase_options.dart` where it says
   `REPLACE_AFTER_REGISTERING_ANDROID_APP`.

### 3. Enable auth providers

In the Firebase console → **Authentication** → **Sign-in method**:
- Enable **Email/Password**.
- Enable **Google** (add your project support email).

### 4. Run

```bash
flutter pub get
flutter run
```

## Project layout

```
lib/
├── main.dart                  # bootstrap: Firebase init, orientation lock
├── firebase_options.dart      # generated by flutterfire — safe to check in
├── app/
│   ├── app.dart               # MaterialApp.router, theme mode
│   └── router.dart            # go_router + auth-aware redirect logic
├── core/
│   ├── auth/                  # AuthRepository + UserProfile stream
│   └── theme/                 # Material 3 theme, LabSpark tokens
└── features/
    ├── onboarding/            # 3-slide carousel
    ├── auth/                  # Login + Role selection
    ├── shell/                 # Bottom nav shell
    ├── home/                  # Dashboard (XP card, quick actions)
    ├── labs/                  # (Phase 3) Lab catalog
    ├── spark/                 # (Phase 5) Ask Spark chat/voice
    ├── practical/             # (Phase 7) CBSE practical PDF
    └── profile/               # Account, role, sign-out
```

## Backend

No backend changes needed for Phase 1. Auth + Firestore use the same Firebase
project as the web app. The Cloud Run backend (`server/` in the web repo) is
consumed starting in Phase 5 (voice) and Phase 4 (grading).
